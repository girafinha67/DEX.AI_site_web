# DEX.AI

Prospecção de empresas sem site, com dados reais do Google Places, para vender
serviços de criação de site.

## Desenvolvimento

Você precisa de Node.js e npm — [instale com nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
